# AI usage

This folder records how AI tools were used to build this project.

| File | Contents |
|------|----------|
| `links.md` | Links to, or exports of, the actual AI chat sessions. Filled in by hand by the author. |
| `../docs/SPEC.md` | The full prompt that was given to the AI coding assistant at the start. |
| `../docs/DECISIONS.md` | Running decision log, including AI suggestions that the author rejected or changed. |

Nothing in this folder is generated or reconstructed after the fact. If a session has no
link or export, it is not listed.
